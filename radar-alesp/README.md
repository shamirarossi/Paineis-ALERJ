# Radar ALESP

Painel interno do gabinete Dani Balbi com os 519 projetos de lei da ALESP (2023–2026), codificados por ideologia do partido autor, tema, tipo de instrumento e status.

- Abra o `index.html` no navegador, ou publique pelo GitHub Pages.
- Tudo fica num arquivo só: dados, fonte OliJo e logo estão embutidos. Precisa de internet só para a biblioteca de gráficos (d3) e a fonte Source Sans.
- Cada projeto tem um link para a página dele no site da ALESP.

Fonte dos dados: planilha "Base de dados ideologia partidária codificada". Para atualizar, gere o painel de novo a partir da nova versão da planilha.
